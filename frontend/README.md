# Documentação Front End

Siga os passos abaixo para configurar o projeto e executar o servidor de desenvolvimento na sua máquina.

## Pré-requisitos

* [Node.js](https://nodejs.org/) (recomendado v18 ou superior)
* [Expo CLI](https://docs.expo.dev/get-started/installation/)

Para instalar o Expo CLI globalmente, execute:

```bash
npm install --global expo-cli
```

## Instalação

Clone o repositório e instale as dependências:

```bash
git clone https://github.com/D-O-S-T/EREMITA.git
cd EREMITA/frontend
npm install
```

## Executando o Servidor de Desenvolvimento

Para iniciar o servidor de desenvolvimento do Expo, execute um dos dois comandos abaixo:

```bash
npx expo start
```

```bash
npm start
```

Isso abrirá o **Expo Developer Tools** no seu navegador.

Você pode então:

* Escanear o QR Code com o aplicativo **Expo Go** no seu celular (disponível para [Android](https://play.google.com/store/apps/details?id=host.exp.exponent) e [iOS](https://apps.apple.com/app/expo-go/id982107779))
* Ou pressionar `I` para rodar em um simulador iOS (apenas no macOS)
* Ou pressionar `A` para rodar em um emulador Android

> [!IMPORTANT]
> Certifique-se de ter o aplicativo **Expo Go** instalado no seu celular para testar o app em um dispositivo real.
